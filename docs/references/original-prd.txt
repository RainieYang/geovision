# GeoVision 智能个人网站 PRD

## 1. 项目定位

项目名称暂定：

**GeoVision**

定位：

**面向海外客户的个人技术品牌网站 + 在线技术 Demo 平台。**

核心方向：

* Real-time Visualization
* WebGIS
* Cesium / OpenLayers
* WebGL
* Three.js
* WebSocket / Binary Streaming
* Industrial Visualization
* IoT Visualization
* RF / Spectrum Visualization
* Digital Twin

网站不是传统个人简历站，而是：

**作品展示 + 技术能力证明 + 在线 Demo + 潜在客户转化入口。**

目标用户：

1. 海外软件外包客户
2. GIS / IoT / Digital Twin 公司
3. 系统集成商
4. 工业设备厂商
5. SDR / RF / 科研团队
6. 招聘方
7. GitHub 开源项目访问者

---

# 2. 产品核心目标

## 2.1 第一目标

让用户进入网站 10 秒内明白：

> 这是一个专门做 Real-time GIS / WebGL / Industrial Visualization 的开发者。

而不是：

> 一个普通 React 前端个人网站。

---

## 2.2 第二目标

通过真正可以操作的 Demo 证明：

* 能做复杂 GIS
* 能做 2D / 3D
* 能处理实时数据
* 能处理大量对象
* 能做 WebGL 高性能渲染
* 能处理频谱 / 瀑布图等专业数据
* 能做工业级 UI
* 能进行系统级可视化设计

---

## 2.3 第三目标

# 4. 颜色规范

主背景：

```css
--bg-primary: #071016;
--bg-secondary: #0B151C;
--bg-card: #0E1A22;
--bg-elevated: #12212B;
```

边框：

```css
--border-primary: rgba(255,255,255,0.08);
--border-hover: rgba(73,200,255,0.28);
```

主文字：

```css
--text-primary: #F1F5F7;
--text-secondary: #8F9DA6;
--text-muted: #5F717C;
```

主强调色：

```css
--accent: #38BDF8;
--accent-hover: #5CCBFA;
```

状态色：

```css
--success: #36C98F;
--warning: #E8B654;
--danger: #F15C5C;
```

原则：

**90% 使用黑灰白，10% 使用蓝青色。**

蓝色只用于：

* CTA
* Hover
* 数据高亮
* 地图轨迹
* 当前状态
* 图表重点

# 42. 性能原则

必须避免：

```text
React State 高频更新地图

每帧触发 React Render

JSON 高频大数据

大量 Entity 无控制创建
```

原则：

```text
UI State → React

Real-time Data → Runtime Layer

Rendering Data → TypedArray / Buffer
```
