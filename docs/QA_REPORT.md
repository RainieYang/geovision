## 性能读数的范围

观察到前台地图短时读数约 53～61 FPS / 5Hz；此前开发过程中也出现过 37 FPS。2D 按数据变化绘制，约 5 FPS 是 5Hz 输入下的正常按需行为。浏览器失去活跃状态时观察到约 1 FPS，因此不能用这组非固定环境读数给出性能保证。

频谱前台短时读数约 30Hz 输入 / 30 FPS，CPU draw p95 约 0.60～1.00ms。这里的 p95 是 SDK 的 JavaScript 绘制调用计时，不是 GPU 耗时。暂停后 UI 输入率与绘制率归零。

没有完成固定设备、固定 DPR/60Hz 显示器条件下的连续 60 秒统计，也没有完成两个 Demo 各连续 20 分钟前台运行与堆/GPU 资源趋势采样。不宣称计划的性能目标已全部通过。

## 已知构建提示与实现边界

- 保留上游固定 Cesium 1.91.0，打包器会提示其 protobufjs 使用 eval；没有通过本任务升级 SDK 引擎版本。
- 地图动态模块约 5.77MB（gzip 约 1.41MB），按需加载；首页启动前不导入地图，首屏应用 JS gzip 约 82KB。
- widgets.css 的构建时路径提示来自静态复制顺序，生产输出中该资源已验证存在。
- 当前数据均为模拟。没有硬件采集、FFT、真实 WebSocket/MQTT 服务、完整回放或星座图。
- 当前分析事件为浏览器本会话记录，不构成生产级跨用户流量统计。
- 原 docs/IMPLEMENTATION_PLAN.md 保留实施前措辞作为历史基线，当前状态以本记录和 README 为准。
